# 发现仓库：审计对象再分类

根据仓库元数据，把 GitHub 仓库分成三种审计对象之一。已有关键词粗分结果，请复核并给出最终判定。只做一轮短判断，不要长思考链或逐步推理，直接输出 JSON。不要编造未提供的目录或源码结构；信息不足时可以维持关键词结果。

## 类别

- `web`：可独立部署的 Web 应用（CMS、后台、自托管服务、站点等），入口主要是 HTTP / 站点。
- `library`：给调用方用的库 / SDK / 解析器 / 组件，不是可独立部署的站点。
- `mixed`：仓库同时含可复用库核心与 demo / sample / examples / 示例 Web。

## 输出

只输出 JSON，不要 markdown 围栏或其它文字：

`{"target_kind":"web|library|mixed","reason":"中文一句，说明为何确认或覆盖关键词结果"}`
